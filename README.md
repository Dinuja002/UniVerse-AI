# UniVerse AI
### Your Smart University Companion

UniVerse AI is a web-based university assistant prototype designed to help University of Vavuniya students access useful university-related information through a simple interface.

## Features

- Interactive chatbot interface
- Question and answer functionality
- Past paper section
- Search and filtering options
- PDF file access
- FastAPI backend

## Technology Stack

- Python
- FastAPI
- Uvicorn
- Pydantic
- HTML
- CSS
- JavaScript

## Project Structure

```text
UniVerse-AI/
│
├── main.py
├── static/
│   └── index.html
└── papers/
    └── sample1.pdf
```

## How to Run Locally

1. Clone this repository.
2. Open the project folder in a terminal.
3. Install the required dependencies.
4. Run the application:

```bash
python -m uvicorn main:app --reload
```

5. Open your browser and visit:

```text
http://127.0.0.1:8000/
```

## Current Project Status

This project is currently a working prototype. The chatbot uses keyword-based demo responses. Online AI API integration and verified university information sources are planned for future development.
